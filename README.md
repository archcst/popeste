# Popaste

macOS 菜单栏提示词工具，支持 macOS 13+。每条提示词保存完整正文，列表用正文开头辨认内容，长内容单行省略。无需账号、网络或第三方依赖。

## 构建与运行

```sh
scripts/build-app.sh
open dist/Popaste.app
```

界面由 WKWebView 加载本地 HTML/CSS，构建时直接复用已确认的设计稿；菜单栏、全局快捷键、系统权限及插入由 AppKit 实现。界面不加载网络资源。

Swift / Command Line Tools 即可构建本机架构的应用。开发构建使用 ad-hoc 签名；公开分发需 Developer ID 签名与公证。

```sh
scripts/test.sh
```

7 组独立 Swift 测试覆盖数据、导入导出、迁移、配置持久化和屏幕位置。无需 XCTest 或完整 Xcode。

## 使用

- 全局快捷键呼出或收起浮窗；设置中可录制。首次默认 Control+Option+Space，迁移时保留已有组合。
- 直接输入搜索正文；置顶优先，然后按使用次数、更新时间排序。
- Ctrl+N/P 或上下箭头选择，Ctrl+F 预览全文，Ctrl+B 返回列表，Enter 插入，Esc 取消。组词期间由输入法处理按键。
- 列表每行是一条提示词的正文。双击插入；浮窗中 Command+Shift+C 复制所选正文，管理界面也有复制按钮。
- 管理界面可新建、编辑、保存、取消、置顶、确认删除、导入和导出。Command+S 保存。
- 管理、设置沿用已确认设计稿的中档尺寸。设置中的浮窗大小提供小（80%）、中（90%）、大（100%），同步调整浮窗、文字、行高和间距；每次呼出应用当前选择。
- Command+1 打开管理，Command+, 打开设置。菜单栏始终提供呼出、管理、设置和退出入口。
- 关闭窗口后继续常驻。仅粘贴正文，不发送 Enter、不提交表单。

## 本地文件

用户指定的数据目录为 **`~/.config/popeste`**（目录名按指定拼写）。

| 文件 | 内容 |
| --- | --- |
| `config.json` | 全局快捷键、浮窗大小、首次使用标记、登录启动偏好、外观 |
| `prompts.json` | 正文、ID、置顶、使用次数、更新时间；版本 2 |
| `migration-v1-backup.json` | 首次迁移时保存的原版提示词文件 |

文件以原子方式写入，权限为 `0600`。首次启动时，若新位置尚无提示词文件，自动从 `~/Library/Application Support/Popaste/prompts.json` 迁移；若尚无配置文件，从旧版 UserDefaults 读取快捷键和首次使用标记。新文件存在时优先读取，旧数据保留作恢复来源。损坏数据会报错，不静默覆盖。

备份导入兼容版本 1 和 2。正文完全一致的条目跳过，其余作为新记录添加；执行前显示数量，现有记录不会被覆盖。版本 1 的完整原始文件保留在迁移备份中。

系统权限和登录项由 macOS 管理，其余上述应用配置均从 `config.json` 读写。手工编辑文件请先退出应用。

## 权限与兼容性

辅助功能用于读取光标附近的位置和模拟 Command+V。无法取得光标位置时回退鼠标附近；缺少授权时可以继续管理和复制。开发构建更换签名后，若系统开关开启但应用仍未获授权，可移除旧的辅助功能条目后重新添加当前应用。

剪贴板在发送 Command+V 后等待 800ms，再仅在 changeCount 未变化时恢复此前可读取的内容。外部应用是否接受粘贴、何时读取剪贴板没有通用确认机制；自绘控件或慢速应用可选择手动复制。
